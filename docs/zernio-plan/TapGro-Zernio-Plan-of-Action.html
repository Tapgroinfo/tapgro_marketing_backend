Social Media for Salons — Plan of Action

TapGro Marketing · Integration with Zernio (one API for Facebook, Instagram, Google Business Profile, YouTube and Meta Ads) · 6 Nov 2026
Summary
  • We use Zernio instead of building directly on Meta / Google / YouTube APIs: launch in weeks, not 4–6 months, and our suspended Meta developer account does not block us.
  • Backend foundation is already built and tested: admin panel, customer app login (mobile OTP), connecting channels through Zernio, channel testing, lead capture from Meta lead forms, webhooks.
  • Remaining work: Zernio account setup (1–2 days), app / panel screens, then posting, analytics and inbox features, a pilot with 5–10 salons and billing.
  • Target: pilot in ~4 weeks, paid launch in ~8 weeks.

1. How it works

StepWhat happens
1. Salon logs inCustomer app: mobile number → OTP → account created. Existing TapGro Hub customers are flagged automatically.
2. Connect channelsSalon taps “Connect Instagram / Facebook / Google”. We get a secure link from Zernio; the owner logs in on Facebook / Google and picks the Page or location. Zernio sends them back to our app.
3. Use featuresOur backend calls Zernio to post, schedule, read analytics, reply to comments / reviews and manage Meta ads for that salon.
4. Stay in syncZernio webhooks tell us when a channel disconnects (token expired), a post is published / failed, or a lead form is submitted → lead appears in the salon’s Leads screen.

Each salon = one Zernio “profile”. Each connected account (Facebook Page, Instagram, GBP location, YouTube channel, Meta ad account) is billed by Zernio per month.

3. Plan of action

Phase 0 — Setup (Day 1–2) · Owner: Tech lead + Manager

  • Create Zernio account (zernio.com), add company card, generate API key. First 2 connected accounts are free.
  • Ask Zernio to enable Ads on our team (needed for Meta lead forms — must be on before salons connect Facebook).
  • Production server with HTTPS domain (e.g. api.tapgro.com); set APP_BASE_URL.
  • In Zernio dashboard add webhook /api/public/v1/webhooks/zernio with a secret; events: account.connected, account.disconnected, lead.received, post.published, post.failed.
  • Save API key, webhook secret, panel & app redirect URLs in TapGro settings → run “Test provider”.
  • Start SMS DLT template approval for login OTP (can take several days).

Done when: provider test passes and a test webhook reaches our integration logs.

Phase 1 — Internal pilot (Week 1) · Owner: Backend + Marketing

  • Connect TapGro’s own Facebook Page and Instagram from the admin panel (uses the 2 free accounts).
  • Run channel health test and one real test post on each.
  • Create a test Meta lead form; confirm the lead arrives in Leads.
  • Disconnect / reconnect once to confirm “needs reconnect” alerts work.

Done when: all four checks pass on real accounts.

Phase 2 — App & panel screens (Week 1–3) · Owner: Frontend / Mobile

  • Customer app: OTP login, profile, “Platforms” screen with Connect buttons (open link in in-app browser, return via deep link tapgro://social), channels list, Leads list / detail / notes.
  • Admin panel: Zernio settings page, social profiles & channels, customers (TapGro flag, block), TapGro member import, leads.
  • All APIs are ready and documented in Swagger (/swagger/customer, /swagger/backend).

  • Plans: Starter ₹999, Growth ₹1,999, Pro ₹2,999 / month (+GST) — from the pricing review.
  • Build payment + subscription (Razorpay), plan limits (number of channels), trial.
  • Turn off OTP test mode, final security review, launch.

7. Risks and how we handle them

RiskMitigation
Dependence on one vendor (Zernio down / price change)All Zernio calls are in one module; can switch provider or move Meta / Google direct later (at ~1,000+ salons). Integration logs show every call.
Facebook / Instagram tokens expireZernio sends “disconnected” → channel marked “needs reconnect”, admin notified, salon shown a Reconnect button.
Meta leads not arrivingAds enabled on Zernio before salons connect; test lead form in Phase 1.
OTP SMS delays (DLT)Start approval now; WhatsApp OTP template as fallback.
Salon data privacyTokens stay with Zernio (SOC 2 / GDPR docs); we store only account ids; secrets masked; signed webhooks.
Accidental public posts while testingTest post requires explicit confirmation; health check is the default test.

8. Success measures (first 3 months)

  • Salons onboarded and % with at least one connected channel
  • Posts published per salon per week; failed-post rate below 2%
  • Leads captured per salon per month
  • Paid conversion from pilot / trial; monthly churn
  • Zernio cost per salon vs plan price (target gross margin above 60%)
